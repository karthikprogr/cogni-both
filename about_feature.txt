═══════════════════════════════════════════════════════════════════════════════
  FEATURE OVERVIEW
═══════════════════════════════════════════════════════════════════════════════

The Dashboard Overview includes a dynamic color palette system that allows users
to customize the visual appearance of all automatically generated charts and 
visualizations. This feature provides four professionally designed color schemes
that adapt all chart types (bar, line, scatter, heatmap, correlation matrix, etc.)
to maintain consistent branding and visual coherence.

KEY BENEFITS:
✓ Professional, cohesive dashboard appearance
✓ Brand customization without manual color picking
✓ Accessibility considerations (contrast, color-blindness)
✓ Context-appropriate color psychology
✓ Instant visual refresh of all charts

═══════════════════════════════════════════════════════════════════════════════
  TECHNICAL IMPLEMENTATION
═══════════════════════════════════════════════════════════════════════════════

FRONTEND (React + Plotly.js):
─────────────────────────────────

File: cognidata/frontend/src/pages/Dashboard.jsx
Component: OverviewTab

State Management:
- useState("Indigo") for selected palette
- useCallback for palette change handler
- useEffect to reload charts when palette changes

User Interface:
- Palette selector buttons (Indigo, Emerald, Sunset, Ocean)
- Active palette highlighted with purple border and background
- Inactive palettes shown with subtle border
- Loading indicator during chart regeneration

Code Flow:
1. User clicks palette button
2. setPalette(newPalette) updates state
3. useEffect detects palette change
4. loadCharts(palette) called with new palette name
5. API request: GET /viz/overview?max_charts=4&palette={palette}
6. Charts regenerated with new color scheme
7. UI updates with new visualizations


BACKEND (FastAPI + Plotly):
─────────────────────────────────

File: cognidata/backend/app/api/routes/viz.py
Endpoint: GET /viz/overview

Service: cognidata/backend/services/agents/viz_agent.py
Function: generate_overview_charts()

Algorithm Flow:
1. Receive palette parameter from frontend
2. Map palette name to Plotly color scale:
   - Indigo → Custom ["#6366f1", "#8b5cf6", "#a78bfa", ...]
   - Emerald → Plotly "Greens" + custom modifications
   - Sunset → Plotly "Hot" + custom warm tones
   - Ocean → Plotly "Blues" + custom cool tones

3. For each chart type (bar, line, scatter, heatmap, etc.):
   - Apply color_discrete_sequence or colorscale parameter
   - Set marker colors based on palette
   - Adjust gradient scales for continuous data

4. Generate 4-6 automatic charts:
   - Distribution charts (bar, histogram)
   - Correlation matrix (heatmap)
   - Relationship charts (scatter, line)
   - Statistical summaries (box, violin)

5. Return JSON with Plotly figure specifications


COLOR GENERATION ALGORITHMS:
────────────────────────────────

1. SEQUENTIAL COLOR SCALES (for continuous data):
   - Method: LAB color space interpolation
   - Formula: L*a*b* = f(base_color, steps)
   - Steps: 10 color stops between light and dark
   - Ensures: Perceptually uniform brightness

2. DISCRETE COLOR SEQUENCES (for categorical data):
   - Method: Hue rotation with fixed saturation/lightness
   - Formula: HSL = (H + i*step, S, L) where i = category index
   - Steps: 360° / num_categories
   - Ensures: Maximum distinguishability

3. GRADIENT GENERATION (for heatmaps):
   - Method: RGB interpolation with gamma correction
   - Formula: RGB_mid = (RGB_start^γ + RGB_end^γ)^(1/γ)
   - Gamma: 2.2 (standard sRGB)
   - Ensures: Smooth visual transitions

4. ACCESSIBILITY ADJUSTMENTS:
   - Contrast Ratio: Minimum 4.5:1 with background
   - Color Difference: Minimum ΔE = 10 in CIELAB space
   - Fallback: Patterns for color-blind users (future enhancement)


═══════════════════════════════════════════════════════════════════════════════
  CHART TYPES AFFECTED BY PALETTES
═══════════════════════════════════════════════════════════════════════════════

The palette system applies to ALL auto-generated charts in the Overview tab:

1. BAR CHARTS:
   - Distribution of categorical data
   - Uses discrete color sequence
   - Each category gets a unique color from palette

2. LINE CHARTS:
   - Time series and trends
   - Uses primary palette color for line
   - Gradient fill under line based on palette

3. SCATTER PLOTS:
   - Relationship between two variables
   - Color-coded by third variable using palette gradient
   - Marker colors from sequential scale

4. HEATMAPS:
   - Correlation matrices
   - Density plots
   - Uses full palette gradient from light to dark

5. HISTOGRAMS:
   - Data distribution
   - Bar colors from palette primary color
   - Gradient based on frequency

6. BOX PLOTS:
   - Statistical summaries
   - Box colors from discrete palette sequence
   - Outliers highlighted with accent color

────────────────────

Frontend (Dashboard.jsx):
1. Add palette name to PALETTES array: ["Indigo", "Emerald", "Sunset", "Ocean", "YourPalette"]

  PERFORMANCE CONSIDERATIONS
═══════════════════════════════════════════════════════════════════════════════

CHART REGENERATION:
- Time: 2-5 seconds for 4 charts
- Optimization: Charts are cached for 5 minutes
- Impact: Changing palette triggers full chart regeneration
- Improvement: Could pre-generate all palettes and cache

BROWSER RENDERING:
- Plotly.js: Hardware-accelerated WebGL rendering
- Memory: ~50MB per chart (4 charts = 200MB total)
- Performance: Smooth on modern devices (2016+)

NETWORK OVERHEAD:
- Request size: ~2KB (palette parameter)
- Response size: ~100KB (4 charts in JSON)
- Total: ~102KB per palette change

═══════════════════════════════════════════════════════════════════════════════
  FAQ - FREQUENTLY ASKED QUESTIONS
═══════════════════════════════════════════════════════════════════════════════

Q1: Do palette changes persist after logout?
A1: Currently no. Palette resets to Indigo on page reload. Future enhancement
    will save preference to user profile.

Q2: Can I customize colors within a palette?
A2: Not yet. Currently limited to 4 pre-defined palettes. Custom palettes
    planned for future release.

Q3: Do palettes affect charts in other tabs (Data Explorer, Charts)?
A3: No. Palettes only affect auto-generated charts in the Overview tab.
    Charts tab uses user-selected colors.

Q4: Why do charts take a few seconds to update after palette change?
A4: Charts are regenerated on the backend with new color scheme. This involves
    re-analyzing data and creating new Plotly figures. Typically 2-5 seconds.

Q5: Are palettes accessible for color-blind users?
A5: Partially. Indigo and Ocean work well for red-green color blindness.
    Sunset works for blue-yellow. Future: pattern overlays for full accessibility.

Q6: Can I export charts with current palette?
A6: Yes! Charts maintain their colors when exported as images from Plotly menu.

Q7: Do palettes affect PDF reports?
A7: Yes, if you generate a report from the Overview tab, it will use the
    currently selected palette.
